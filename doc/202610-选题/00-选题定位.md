# 选题定位

> 项目：`cvr-debias`　层次：本科（数据科学与大数据技术）　口径：1.8–2.5 万字，6 个模型配置（3 基线 + 3 方法变体），创新点 C1 + C2 + C5

## 1. 题目

**中文**：面向样本选择偏差的电商点击后转化率纠偏方法研究与系统实现

**英文**：Debiasing Post-Click Conversion Rate Estimation under Sample Selection Bias: Method and System

主数据集 Ali-CCP，备选 AliExpress 五国。目标期刊（可选，答辩后做）：IPM / KBS / ECRA。

## 2. 一句话问题

CTR 预估里每条曝光都有标签；CVR 预估里只有被点击的样本才带转化标签。模型在点击样本上训练，却要在全部曝光上推理，因此会系统性高估转化率。

Ali-CCP 的稀疏度决定了这件事有多难：8400 万曝光、340 万点击（4.0%）、约 1.8 万转化（CVR ≈ 0.53%，CTCVR ≈ 0.021%）。96% 的推理空间从未进入 CVR 训练，而纠偏带来的方差增长很容易超过它消除的偏差。

## 3. 研究主线

**有偏训练集 → 全空间建模 → 因果加权纠偏。**

- 全空间建模：ESMM 的乘法分解 pCTCVR = pCTR · pCVR，让 pCVR 在曝光空间被间接监督；
- 因果加权：IPS / DR 把点击空间的朴素风险改成全空间风险的无偏估计；
- 纠偏不稳的根因：现有方法把倾向得分（pCTR）当作可靠输入，但它本身就是一个**有偏、未校准、重尾**的估计量。

## 4. 本科口径的三个创新点

| 编号  | 创新点      | 针对的问题             | 技术实现                                             | 如何证明有效                              |
| --- | -------- | ----------------- | ------------------------------------------------ | ----------------------------------- |
| C1  | 校准倾向头    | 倾向未校准、长尾 1/e 权重爆炸 | CTR 头输出经温度标度校准；按验证集分位数自适应截断 τ                    | 1/e 权重分布箱线图（校准前后）、ECE 下降、半合成上真实偏差下降 |
| C2  | 方差正则双重稳健 | DR 方差大、插补误差不受控    | 插补塔目标改为 DR 方差上界的加权平方误差（MRDR 形式），与 C1 联合          | 偏差–方差分解、不同转化稀疏度下的稳定性曲线              |
| C5  | 半合成偏差基准  | 真实数据上无法度量真实偏差     | 可控 logging policy 按 β 生成 MNAR 点击，β = 0 无偏、β 越大越偏 | 本身即方法论贡献；β–偏差曲线是全文最有说服力的单张证据        |

C3（因果解耦专家路由）与 C4（自适应多任务权重）**进展望章**，代码保留、不做主实验。C1 + C2 + C5 是不可删减的最小可发表集合。

## 5. 与 2025 届「广告点击率预测系统」的本质差异

不在模型复杂度，而在**标签的可观测性**。CTR 每条曝光都有标签，CVR 只有点击样本有标签。这一句差异决定了全文技术主线，也决定了评估指标必须以 PCOC、ECE、半合成偏差这类「校准性」证据为主，而不是只报 AUC。
