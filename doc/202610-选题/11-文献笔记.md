## 第 1 则：华为云社区《多任务学习之ESMM模型》

- 来源：https://bbs.huaweicloud.com/blogs/362298
- 作者 / 时间：野猪佩奇996，2022-06-29
- 性质：学习总结 / 教程，**无实验数据、无复现结果**
- 抓取情况：正文读到 2.3 节第 1 个问题为止（约 16.7 KB），第 3 节「ESMM 代码详解」未取到

### 1. 内容骨架

| 小节 | 讲了什么 |
| --- | --- |
| 1.1 | 多任务学习的动机、四种可能结果、两类研究问题（网络结构设计 / 多 loss 优化） |
| 1.2 | loss 加权融合：Youtube DNN 的 Weighted CE（时长作正样本权重）、人工权重 0.3/0.7 |
| 1.3 | Shared-Bottom：共享底层 + 各任务 Tower，loss 直接相加；硬共享 → 软共享的演进判断 |
| 2.1 | 传统 CVR 的 SSB 与 DS，配曝光 / 点击 / 转化三层样本空间示意 |
| 2.2 | 乘法分解、双 loss、embedding 共享带来的迁移学习与稀疏缓解 |

### 2. 与本课题的对齐点

| 文章表述 | 本课题对应 | 判断 |
| --- | --- | --- |
| `pCTCVR = pCTR × pCVR`，曝光→点击→转化显式依赖 | 02 文档 §1 的乘法分解，公式同构 | 一致 |
| SSB：训练集是点击子集，预测时面对曝光全集 | 02 文档形式化为 `o_i = y_i`、`e_i = pCTR_i`，并接到 IPS / DR | 我们用因果语言做了升级 |
| DS：点击占曝光少，转化占点击更少 | 08 文档已有实测的逐级比率 | 文章只有定性描述，我们可反补量化 |
| 「CTR=0、CVR=1 为不合法样本，需删除」 | 06 文档清洗规则 C2 | **关键外部印证** |
| 只有 CTR loss 与 CTCVR loss 两项，pCVR 是中间变量 | 基线 ESMM 实现口径 | 复现检查点 |
| Shared-Bottom 任务相关性低时负收益 | 02 文档 C3 解耦专家即软共享 | 对应 |
| 多 loss 难点是「数值有大有小、学习有快有慢、更新方向时而相反」 | 02 文档 §2.2 C3 实测：λ 名义小、梯度并不小 | **可作论据** |
| DIVISION（分别训 CTR 与 CTCVR 再相除）优于 BASE 但弱于 ESMM，因 pCTR 很小 | 02 文档 C1 的校准 + 分位数截断 τ | **最有价值的一条** |

### 3. 三条可直接采用的论据

**3.1 非法样本规则有独立印证。**
文章明确写「CTR=0、CVR=1 的样本为不合法样本，需删除」，与 06 文档 C2 一致；08 文档实测 train 230 条、test 226 条（约占转化样本 2.5%）。说明 C2 不是本项目自定的规则，而是该数据上的通行处理。
注意：这是**工程实践佐证**，论文里不能引博客，需落到原始论文或数据集说明。

**3.2 DIVISION 消融支撑 C1 的动机。**
文章转述 ESMM 原文的消融：先分别训 CTR 与 CTCVR 两个模型、再相除得 CVR，效果优于 BASE 但弱于 ESMM，原因是 pCTR 通常很小，除法会放大小分母误差。
与本课题的关系：DR / MRDR 中的 `1/ẽ_i` 是同一类数值风险（**不同环节**：一个在预测端相除，一个在损失端加权）。它不能直接证明 IPS 必须截断，但说明「CVR 场景下小分母放大误差」是已被观察到的真实现象，为 C1 的截断设计提供外部动机。
更直接的理论依据仍是 ESCM² 的 IEB 分析，二者配合使用：前者是现象，后者是机理。

**3.3 DS 可以量化，不必停在定性。**
用 08 文档与 `90_reports/01_probe/label_stats.json` 的数字：

| 量 | train | 说明 |
| --- | --- | --- |
| 曝光 | 42,300,135 | 全空间 |
| 点击 | 1,644,256 | CTR 3.887% |
| 转化（清洗后） | 8,802 | CVR 0.535% |
| CTCVR | — | 0.0208% |

曝光→点击约 25.7 倍收缩，点击→转化约 187 倍收缩，合计约 4800 倍。这组数字是「从点击空间退到曝光空间」的量化理由，比引用二手描述更有说服力，且符合 02 文档 §4.1 的引用纪律（表 1 统计量只来自自己的 `stats.py`）。

### 4. 三条不能直接采用的表述

1. **Shared-Bottom ≠ ESMM**。Shared-Bottom 是共享底层 + 各任务 loss 相加；ESMM 是共享 embedding + 独立塔 + **对 CTCVR 施加乘积约束**。文章分了两节，但复现时最易混淆。
2. **loss 加权不是多任务建模**。文章自己指出 0.3/0.7 加权「本质上是将不同目标转化为同一个目标」，权重需靠 AB 测试确定。这句可反用来支撑本项目采用 UWL 而非人工权重。
3. **不能引博客**。UWL、GradNorm 文章只提了名字，没有实现细节；引二手材料会被追问。引用清单见第 6 节。

### 5. 未覆盖的部分（即本课题的空白区）

文章停在「结构层」，没有进入「估计层」：

- pCTR 本身估不准时，权重会怎样 → 校准（C1）
- 重要性权重的方差与偏差如何权衡 → C2 与命题 P2 / P3
- 如何在可控偏差强度下做方法间比较 → C5 半合成基准
- 只有 AUC 视角，没有 PCOC / ECE 这类校准与系统性高估的度量

这四点可直接写进论文第 3 章的 gap 陈述。

## 第 2 则：ESCM²（原始论文，SIGIR 2022）

- 来源：arXiv:2204.05125；SIGIR 2022, pp. 363–372
- 作者：Hao Wang, Tai-Wei Chang, Tianqiao Liu, Jiajun Huang, Zhi Chen, Chun Yu, Rui Li, Wenjie Chu
- 抓取情况：**只读了摘要与引言**，DR regularizer 的完整公式与实验表格未逐条核对（标记为待补）

### 1. 内容骨架

| 点 | 要点 |
| --- | --- |
| 问题 | ESMM 的乘法分解缓解了 SSB，但存在两个未解问题：**IEB**（Ideal Error Bound 不可达）与 **PIP**（Prediction Independence Property 不满足） |
| 方法 | 在 ESMM 上加入 **counterfactual risk minimizer** 作为正则项，得到 ESCM² |
| 正则形式 | 论文写作 `R_DR(φ_CTR, φ_CVR, φ_IMP)`，由误差项与插补项组成 |
| 验证 | 离线数据集 + 线上 A/B；声称同时缓解 IEB 与 PIP，优于基线 |

### 2. 与本课题的对齐点

| ESCM² 表述 | 本课题对应 | 判断 |
| --- | --- | --- |
| DR regularizer 作用于 CVR 预测 | 本项目 `ESCM²-IPS` / `ESCM²-DR` 两个变体 | 直接沿用 |
| 插补塔 φ_IMP 独立于 CVR 塔 | `uc_escm.py` 的 `imp_tower` 与 `cvr_tower` 分开 | 结构一致 |
| 解决 IEB（本质是 SSB 的界） | 02 号 §3 的命题 P1 | 一致 |

### 3. 三个必须写进论文的边界

1. **C2 的方差加权项不是 ESCM² 原文的贡献**，来源是 MRDR（ICML 2018）。ESCM² 提供的是 DR 正则的全空间框架，两者要分开致谢。
2. **ESCM² 的 DR 正则对 CVR 塔的梯度与 IPS 同构**（本项目实测：`max|grad_DR − grad_IPS| = 0`，见 12 号 E34）。这不是实现 bug，是 DR 估计量的数学性质——插补项不含 CVR 参数。若论文声称「DR 带来更好的排序」，必须给出机制解释，否则会被追问。
3. **PIP 是否满足要看实现**：本项目 `cvr_tower` 与 `ctr_tower` 输入相同但参数独立，需确认是否满足原文的独立性定义，待核对原文公式。

### 4. 落点

- 论文 §2.3 相关工作：ESCM² 是本文最直接的前作，需说明「我们沿用它，改进点是 C1 校准 + C2 方差正则 + C5 基准」
- 论文 §4.5 边界说明：明确 DR 正则的梯度同构问题，把贡献定位在**估计量方差**而非**排序能力**

## 第 3 则：MRDR（原始论文，ICML 2018）

- 来源：arXiv:1802.03493；ICML 2018, PMLR 80:1447–1456
- 作者：Mehrdad Farajtabar, Yinlam Chow, Mohammad Ghavamzadeh（Google DeepMind）
- 抓取情况：**只读了摘要**，方差上界的具体推导与权重 `(1−e)/e²` 的出处未逐式核对（标记为待补）

### 1. 内容骨架

| 点 | 要点 |
| --- | --- |
| 场景 | 强化学习的 **off-policy evaluation**：用行为策略产生的数据评估目标策略 |
| 问题 | 标准 DR 估计量虽然无偏，但**方差可能很大**，尤其倾向得分小时 |
| 方法 | 提出 **MRDR**（More Robust DR）：直接学习使 DR 估计量**方差最小**的模型参数 |
| 关键 | 推导方差关于模型参数的梯度，可从样本估计，从而端到端最小化方差 |
| 结论 | 理论上证明优于标准 DR，实验中方差更低、更稳健 |

### 2. 与本课题的对齐点与差异

| MRDR | 本课题 | 差异 |
| --- | --- | --- |
| RL 的 off-policy evaluation | CVR 的 SSB 纠偏 | **领域不同**：动作/奖励 → 点击/转化 |
| 最小化 DR 估计量方差 | 插补塔目标改为方差上界加权 MSE | 形式迁移 |
| 权重来自方差推导 | `w = click·(1−ẽ)/ẽ²` | **待核实**：MRDR 原文的权重是否就是这个形式 |

### 3. 三个风险点

1. **迁移依据要写清**：RL 的 OPE 与 CVR 的 SSB 在数学上都是「用有偏样本估计反事实风险」，可以建立对应，但不能直接说「MRDR 证明了 CVR 上有效」。
2. **权重形式必须逐式核对**：如果 `(1−ẽ)/ẽ²` 与 MRDR 原文不一致，C2 的「来源」就要改写。当前标记为**待核实**。
3. **不能写成「MRDR 的 CVR 版本」**：审稿人会问「你自己做了什么」。正确表述是「借鉴 MRDR 的方差正则思想，在 ESCM² 全空间框架下重新推导插补目标」。

### 4. 落点

- 论文 §4.5：C2 的来源声明，必须引 ICML 2018 原文
- 论文 §4.4：方差正则的推导，需要自己重写一遍在 CVR 场景下的形式，不能只引 MRDR
