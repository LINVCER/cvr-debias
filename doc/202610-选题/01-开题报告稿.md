# 开题报告稿

> 题目：面向样本选择偏差的电商点击后转化率纠偏方法研究与系统实现
> 层次：本科（数据科学与大数据技术）　主数据集：Ali-CCP　备选：AliExpress 五国
> 说明：本稿按本科口径撰写（约 1.8–2.5 万字论文的浓缩版），可直接用于开题答辩。

## 一、选题背景与意义

电商与信息流广告的计费与排序依赖两个概率：点击率 pCTR 与点击后转化率 pCVR。排序常用 pCTCVR = pCTR · pCVR，出价与 ROI 测算则依赖 pCVR 本身。pCVR 估偏会直接传导到流量分配与广告主成本：预测偏高会导致出价虚高、预算浪费；预测偏低会错失高价值流量。

问题的特殊性在于**标签的可观测性**。CTR 预估中每条曝光都有点击标签；CVR 预估中只有被点击的样本才可能产生转化标签。于是训练分布（点击空间）与推理分布（曝光空间）不一致，这就是样本选择偏差（Sample Selection Bias，SSB）。用户是否点击又由用户偏好与旧系统排序共同决定，属于非随机缺失（MNAR），无法用简单的缺失值填补处理。

Ali-CCP 的规模把这一问题的两个侧面放大到极端：

| 层级  | 规模（官方口径）  | 占上一级比例       | 本项目实测                |
| --- | --------- | ------------ | -------------------- |
| 用户  | 约 40 万    | —            | **44.5 万**（train 294,882 / test 295,787，并集 444,861） |
| 公共特征组 | —         | —            | train 730,600 组 / test 884,212 组（组/用户 = 2.48 / 2.99，**非用户数**） |
| 商品  | 约 430 万   | —            | 未单独统计                |
| 曝光  | 约 8400 万  | —            | **85,316,975**       |
| 点击  | 约 340 万   | 约 4.0%       | **3,317,703**（3.89%）  |
| 转化  | 约 1.8 万   | 约 0.53%（对点击） | **18,453**（0.556%）   |

> 口径说明：Ali-CCP 的骨架表第 3 列官方名是 **`common_feature_index`（公共特征组索引）**，不是用户 ID；真正的用户 ID 是特征域 **101**。42,300,135 条曝光 ÷ 730,600 组 ≈ 57.9 条/组，一个索引约对应一次请求页。本轮实测 101 的唯一值 train 294,882 / test 295,787、并集 **444,861**（重合 145,808），与官方「约 40 万」同阶，故用户规模按实测 44.5 万计。**train 与 test 取自不同时间窗，两段组数不可相加。** 左三列为官方描述，右列为本项目实测（E1/E12/E33b）。CVR 原始 0.556%，清洗后 train 0.535% / test 0.549%（`stats.json`）。

96% 的推理空间未进入 CVR 训练，而约 1.8 万正样本要支撑百万级特征表的 embedding 学习。两者耦合的后果是：**纠偏带来的方差增长，很容易超过它消除的偏差**。

因此本选题的意义有三层：

1. **方法层**：把「校准倾向得分」与「方差正则双重稳健」联合起来，让纠偏从「能用」变成「稳定可用」；
2. **评估层**：构造可控偏差强度的半合成基准，使「纠偏是否真的有效」第一次可以被直接度量，而不是只看 AUC；
3. **工程层**：在 8400 万行真实日志上用 Hive + Spark 建全空间训练管道，复现三类方法并交付带校准监控的服务原型——这对数据科学与大数据技术专业是核心工作量。

## 二、国内外研究现状

### 2.1 CVR 预估与样本选择偏差

朴素做法是在点击样本上训练一个 MLP 做 CVR 二分类。它完全忽略 SSB，线上会系统性高估。ESMM 提出乘法分解，用全空间的 CTR 与 CTCVR 双任务监督，把 pCVR 作为中间量隐式学得，显著缓解 SSB，但存在固有估计偏差（Inherent Estimation Bias，IEB）：pCVR 被强行耦合在 pCTR 上，且只由其他两个任务的乘积间接约束。

### 2.2 全空间多任务结构

MMoE 用专家分解 + 门控缓解任务冲突，PLE 进一步分离共享与专属专家，缓解负迁移。这类工作只解决任务冲突，完全没有触及 SSB；把它们直接套到 CVR 上，偏差依然存在。

### 2.3 因果纠偏

IPS 用逆倾向加权把点击空间风险改写成全空间风险的无偏估计；DR 叠加插补模型，在倾向或插补任一正确时无偏。Multi-IPW / Multi-DR 把倾向估计交给多任务共享塔，ESCM² 进一步在全空间反事实风险上叠加全局风险正则，明确提出潜在独立优先（PIP）与固有估计偏差两个概念。DCMT 用反事实双塔直接在全空间建模。

这条线留下两个共同缺口：

- 倾向得分被当成可靠输入，但它是从有偏数据中学出来的估计量，**未校准且重尾**；长尾 pCTR → 0 时 1/e 权重爆炸；
- 插补模型的误差不受约束，DR 的方差没有上界。

### 2.4 倾向校准与方差控制

温度标度（temperature scaling）是后处理校准的常用手段；MRDR（More Robust Doubly Robust）从 DR 估计量的方差上界出发，推导出加权平方误差作为插补目标。二者分别解决了「校准」与「方差」的一半问题，但没有在 CVR 全空间框架下联合分析，也没有回答「截断阈值该取多少」。

### 2.5 缺口小结

> 纠偏方法把倾向得分当作可靠输入，但它自己就是一个有偏、未校准、重尾的估计量。

由此确定本研究的三个动作：校准倾向（C1）、约束插补误差（C2）、用可控基准给出真实偏差（C5）。

## 三、研究内容

1. **数据工程与半合成基准**：Ali-CCP 预处理流水线（Hive 分层表 + Spark 原生算子解析 + 词表构建 + 统计产出），以及可控 logging policy 的半合成偏差数据集。
2. **基线复现与偏差诊断**：复现 MLP-CVR、ESMM、MMoE、ESCM²-IPS、ESCM²-DR，用 PCOC 与 ECE 量化各方法的系统性高估程度，验证 IEB 是否真实存在。
3. **UC-ESCM 模型**：在校准倾向（温度标度 + 分位数截断）与方差正则双重稳健的基础上，给出完整目标函数与退化关系表；C3/C4 作为结构展望。
4. **实验与系统**：6 个模型配置（3 基线 + 3 变体）× 5 种子主实验，消融、敏感性、转化稀疏度压力测试，半合成 β 扫描；本机 Docker Compose 演示环境与 PCOC 监控。

## 四、技术路线

```
原始 csv（骨架表 + 公共特征表）
   │  Spark：原生算子解析特征串 → 23 域采集、23 域建模（公共域按曝光级统计词表）→ join → Parquet 分片
   ▼
全空间训练样本（曝光 / 点击 / 转化，双标签）
   │  教师 CVR 模型 → 伪真值 p* → π_β 采样 → 半合成基准（β = 0…4）
   ▼
模型层：MLP-CVR | ESMM | MMoE | ESCM²-IPS | ESCM²-DR | UC-ESCM
   │  损失层：BCE / ESMM 双项 / IPS / DR / 方差正则 DR
   ▼
校准层（验证集后验拟合 T 与 τ，不进训练图）
   ▼
评估层：CVR AUC、CTCVR AUC、CTR AUC、PR-AUC、GAUC、ECE、PCOC、Bias/MSE
   ▼
系统层：ONNX 导出 + 校准参数热更新 + Grafana PCOC 监控
```

阶段划分与验收标准见 `03-里程碑与验收.md`。三条原则先定死：

- 评估协议在跑第一个模型之前定死，禁止先跑再挑指标；
- 所有超参与校准参数在独立验证集上选定，测试集只用于最终报告；
- 每配置 5 种子，报 mean ± std，并对最强基线做配对 t 检验 + Holm 校正。

## 六、数据与实验方案

**数据**：Ali-CCP 主集（train 切 5% 作验证集，test 原样）；AliExpress 五国为可选泛化验证。

**对比模型**（6 个配置）：
- 3 个基线：MLP-CVR（点击空间）、ESMM、MMoE
- 3 个方法变体：ESCM²-IPS、ESCM²-DR、**UC-ESCM（本文方法）**

**指标**：

| 指标               | 空间      | 作用                          |
| ---------------- | ------- | --------------------------- |
| CVR AUC / PR-AUC | 点击空间    | 与文献对齐的主指标；PR-AUC 在极端不平衡下更敏感 |
| CTCVR AUC        | 全曝光     | 最接近线上排序效果                   |
| CTR AUC          | 全曝光     | 确认纠偏没牺牲 CTR（下降超 0.002 需解释）  |
| GAUC             | 点击空间按公共特征组 | 组内排序（近似请求页级）；剔除无正或无负的组并报组数保留比例 |
| ECE（10 等频桶）      | 两个空间    | 校准质量，C1 的直接证据               |
| PCOC = Σŷ / Σy   | 两个空间    | 整体高估倍数，> 1 为高估              |
| Bias / MSE vs p* | 半合成全标签集 | 真实纠偏效果，只做方法间相对比较            |

**消融**：去 C1（T=1、α=0）、只留截断不做校准、去 C2（插补换普通 MSE）、去 C3（专家全共享）、去 C4（权重固定为网格最优）、全去（应等于 ESCM²-DR，用作实现正确性自检）。

**敏感性**：α ∈ {0, 0.001, 0.005, 0.01, 0.05}、λ_orth 对数网格、专家数与三组划分比例、embedding 维度 ∈ {8, 16, 32}。

**稀疏度压力测试**：转化正样本下采样到 100% / 50% / 25% / 10%，画各方法衰减曲线。若 UC-ESCM 的优势随稀疏度加剧而扩大，这是比主表更有说服力的证据。

**算力**：本科口径约 120–180 GPU·h（6 个模型配置 × 5 种子 + 消融 + 半合成），单卡 24 GB 即可；排期按 4–5 周留。
