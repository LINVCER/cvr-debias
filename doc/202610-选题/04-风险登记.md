## 2. 需要提前做的三件事

1. **R2 的对照实现先拉下来**（W7 之前）。不要等到自己写完 ESMM 才发现对不上——官方实现是唯一的仲裁者。同时用以下三条口径做结构核对，任一条不符都会让 CVR AUC 差出量级：
   - ESMM 只训练 **CTR loss + CTCVR loss 两项**，pCVR 是乘法链上的中间变量，不是第三个独立监督；
   - CTCVR 的预测必须是 `pCTR × pCVR` 的**乘积**，不能另起一个独立 Tower；
   - 共享的是 **embedding 层**，不是整个底层；CTR / CVR 两个塔各自独立。
2. **R5 的判断标准先写死**。在跑主实验之前就把「什么叫显著」定义好（配对 t 检验 p < 0.05 且 Holm 校正后仍显著），避免事后挑指标。
3. **R7 的基准自检脚本先写**。β = 0 时朴素 CVR 与 DR 的偏差应当接近，这是基准正确性的唯一硬证据；不通过就不许开始主实验。

## 4. 一句话原则

风险不是靠「小心一点」规避的，是靠**提前定义信号 + 提前写下降级动作**。上表中每一行在触发时都应当是一次「切换」，而不是一次「讨论」。
