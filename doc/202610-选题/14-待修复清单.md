### D4　`detach_imp=True` 让 DR 的 CVR 梯度等同于 IPS

**证据等级：已证实**（`src/losses/causal.py`，数学上是恒等式）

```python
imp_for_dr = imp.detach()
dr = (imp_for_dr + click * (delta - imp_for_dr) / e).mean()
```

`imp_for_dr` 对所有参数是常数，所以对 CVR 塔求导只剩 `mean(click · ∂δ/∂θ / e)`——
与 `ips_loss` 的梯度**逐项相同**。插补塔又是独立塔（不与 CVR 共参），
于是 ESCM²-DR 与 ESCM²-IPS 对 CVR 塔的学习信号完全一致，差异只剩两条间接路径：
插补塔梯度经共享 embedding 回流，以及不确定性加权的任务数从 3 变 4。

**影响**：C2 整个创新点挂在这上面。主表里 DR 和 IPS 两行拉开差距就解释不了机理，
拉不开就被问「双重稳健体现在哪」。因果位置见 §2.1。

原来的 detach 理由是对的：`∂dr/∂imp = (1 − click/e)/N`，而 `e.clamp_min(τ)` 把小倾向样本的
`click/e` 压小了，于是 `E[1 − click/e] > 0` 恒正，imp 被持续推低到 −1e12。但 detach 是把机制一起关掉了。

**修法**：在 10% 上跑 3 配置 × 3 种子对比，半天出结果：

| 方案 | 做法 | 代价 |
| --- | --- | --- |
| A 自归一化权重（推荐） | `w = (click/e) / mean(click/e)`，则 `mean(1−w) ≡ 0`，漂移项在每个 batch 内恒等消失 | 改 5 行；SNIPS 是可引的标准估计量（Swaminathan & Joachims, NeurIPS 2015） |
| B 只靠 clamp | imp 已加 softplus+clamp，漂移结构上不可能再发生，试 `detach_imp=False` | 零成本，但 clamp 会在边界堆积 |
| C 保留 detach | 论文改口径，不再声称 DR 优于 IPS | 省事，但 C2 基本废掉 |

A 有附带好处：自归一化本身就是方差缩减，和 C2 的主线一致，能写进论文而不是当 bug 修掉。

**SNIPS 落地前必须先排查三点**（首轮演练 snips 0.4543 < 0.5，不正常）：

1. 归一化因子在哪个集合上取均值——全体曝光，还是仅点击样本；
2. `Z` 有没有 detach——不 detach 会产生反号项，是唯一能把 AUC 推到 0.5 以下的机制；
3. 是否逐 batch 归一化——650 个重尾样本估 `Z` 噪声极大，应改 EMA。

**验收**：DR 与 IPS 在 CVR AUC 或 Bias 上出现可解释的分离；`tests/test_dr_unbiased.py` 仍通过。

**首轮演练数字的取样口径（2026-11-10 核对）**：9 个 run 均实际存在（10% 子集、10 epoch，21:04–21:42），
§8 里的 0.4910 / 0.5065 / 0.4543 是**各臂 3 个种子的算术平均**（不是中位数），**不含 `_stale`**；
实测与原文一致，原值不改。

| `dr_cmp_ips` | 0.5063 | 0.4788 | 0.4880 | 0.4910 |
| `dr_cmp_detach` | 0.5110 | 0.4989 | 0.5095 | 0.5065 |
| `dr_cmp_snips` | 0.4588 | 0.4409 | 0.4631 | 0.4543 |

### D6　α 的选择准则两项量纲不可比，已退化

**证据等级：已证实（量纲已证实，退化已复现）**（`src/calibration/temperature.py`）

```python
score = ece(click_t.numpy(), e.numpy()) + var_weight * rel_var
```

`ece` 是概率单位，CTR 头上典型量级 0.001–0.01；`rel_var` 是 1/ẽ 的变异系数平方，无量纲，
量级 O(1) 到 O(100)。`var_weight = 0.5` 没有依据，两项相加时 ECE 的贡献大概率在 1% 以下。

你修掉的那个退化（ECE 算在未截断的 ẽ 上 → 对 α 恒定）是对的，但量纲失衡会从另一条路通向同一个结果：
**准则实际只看方差，永远选最大的 α**。若如此，C1 声称的「α 由校准误差与权重方差的加权和决定，
区别于固定 clip 阈值」就不成立——它等价于一个固定阈值，只是藏在分位数里。图 8 的单峰曲线也画不出来。

**验证（已完成，2026-11-10）**：翻 `artifacts/runs/main` 下 33 份 metrics（30 份正式 + 3 份 `_stale`），
**27 份跑过校准的 run 的 `metrics.calibration.alpha` 全部为 0.05（网格上界）**，
另 6 份为 0.0，见下条。

**6 份 α=0.0 的来历（2026-11-10 核对）**：全部是 `mlp_cvr_bce`（5 个正式种子 + 1 份 `_stale`）。
`train.py:446` 只在 `val_pred["ctr"] is not None` 时进入校准段，而 `calib` 的初值在第 391 行是
`{"temperature": 1.0, "tau": 0.0, "alpha": float(loss_cfg.get("alpha", 0.0))}`——mlp_cvr 没有 CTR 塔，
`predict` 返回的 `ctr` 为 None，整段跳过，记录的是默认值。**不是「网格选到 0」，也不是准则退化**；
这 6 份的 metrics 里确实没有 `ctr_exposure` 块，只有 `cvr_click_space`、`ctcvr_exposure`、`calibration`。
结论：统计 α 退化只用另外 27 份。

**修法**：两项化成相对量，`var_weight` 才真在做权衡。

```python
base_ece = ece(click, calib.numpy())      # α = 0 时的 ECE
base_var = rel_var_at(alpha=0.0)
score = ece_a / max(base_ece, EPS) + var_weight * rel_var_a / max(base_var, EPS)
```

**顺带**：默认网格 `(0.001, 0.005, 0.01, 0.05)` 缺 `0.0`。图 8 要展示单峰必须有「不截断」这个左端点，
而且 4 个点画不出峰——加到 7–8 个点、含 0。

**验收**：α 在不同种子/轮次下不全取同一值；图 8 出现可见的内部最优点。

**2026-11-11 复核（与 D6 合并处理，不单开条目）**：本轮 3 次冒烟 + 30 epoch 对照，

## 4. M 系列：指标与校准实现

### M1　bias_and_mse 缺偏差–方差分解

**证据等级：已证实**

当前只返回 bias 与 mse。但 00 文档里 C2 的证明方式写的是「偏差–方差分解」，代码里没有对应实现。
没有这个分解，C2 在实验上没有直接证据。

还有一个实际问题：有符号偏差会抵消。用冒烟表说明——

| 模型 | Bias vs p-star |
| --- | --- |
| esmm | 0.068 |
| mmoe | -0.014 |
| uc_escm | 0.252 |

mmoe 的 -0.014 看着最好，但它是负的，很可能是高 p-star 样本上低估、低 p-star 样本上高估相互抵消。
只报有符号偏差，mmoe 会被误判成最优。

**修法**：

```python
diff = pred - truth
bias = float(diff.mean())
var = float(diff.var())
return {"bias": bias, "abs_bias": abs(bias), "var": var,
        "mse": float((diff ** 2).mean()),
        "rel_bias": bias / float(truth.mean())}
```

**验收**：断言 mse 约等于 bias 平方加 var（容差 1e-9），进单测。

### M2　average_precision 未处理分数并列

**证据等级：已证实**

`np.argsort(-s, kind="mergesort")` 是稳定排序，并列时顺序由索引决定，而 `metrics.py:41-48`
是逐样本累加 `d_rec · prec`，并列被拆成多步，所以 AP 会随样本顺序漂。

原先「sklearn 也是这样、不算错」的判断不成立：sklearn 的 `precision_recall_curve` 按**唯一阈值**聚合，
并列样本落在同一阈值点，AP 对并列不敏感。本仓库的实现不属于这个口径。

**修法（实现口径已定，2026-11-10）**：选**自实现 + 按唯一阈值聚合**，不引入 sklearn 依赖。
理由：`metrics.py` 目前只依赖 numpy，为一个 AP 拉进 scikit-learn 不划算；且聚合后能顺手输出
`n_unique_scores`，便于判定指标是否可信。

落点：`src/evaluation/metrics.py:36-48` 的 `average_precision`。

- 保留 37–41（转数组、`y.sum()==0` 保护、`np.argsort(-s, kind="mergesort")`）；
- 43–48 的逐样本累加改成「先按唯一分数取组尾位置，再累加」：

```python
order = np.argsort(-s, kind="mergesort")
y, s_sorted = y[order], s[order]
# 并列分数归入同一阈值点，取每组的最后一个位置
last = np.r_[np.nonzero(np.diff(s_sorted))[0], y.size - 1]
tp = np.cumsum(y)[last]
fp = (last + 1) - tp
prec = tp / np.maximum(tp + fp, EPS)
rec = tp / max(tp[-1], EPS)
return float((np.diff(np.r_[0.0, rec]) * prec).sum())
```

- `binary_metrics` 的返回里加 `n_unique_scores = int(np.unique(s).size)`。

**重算范围**：

- 只有 `metrics.json → metrics.cvr_click_space.pr_auc` 会变；AUC / GAUC / ECE / PCOC 都不受影响。
- 影响 42 份 metrics：30 份正式 + 3 份 `_stale` + 9 份 `dr_cmp_*`。真正会动的只有分数高度集中的 run
  （坍缩的 dr/vrdr 与 snips 臂）；正常 run 唯一分数接近样本数，AP 变化应在 1e-4 以内。
- 不需要重训，但**需要重新前向**：仓库没有保存 test 预测（`train.py:483` 的 `test_pred` 只在内存里），
  只能加载 `artifacts/models/*.pt` 重跑一次 test，单 run 分钟级。
- 时间点：并入批次 2（与 M1、M3 一起改）。批次 3 全量重跑后自然生效；不要在批次 1 之前单独重算——
  数据要重建，重算出来的数会再次作废。

**验收**：同一组分数打乱输入顺序 10 次，AP 不变；坍缩 run 的 `n_unique_scores` 能被看出来。

### 5.1 三个决策的结论

| 决策 | 结论 | 理由 |
| --- | --- | --- |
| 教师模型 | MLP-CVR 架构，但换一套配置（dim 32、加深一层、用全部点击样本） | 纯 CVR 任务的直觉是对的，但不能与主表里的 MLP-CVR 同构，否则 R7 会被问「教师就是选手之一」 |
| 基准规模 | 全量造伪真值，扫描全部在 10% 上做，全量只复核一个 beta 点 | 造数据便宜（1-2 小时），贵的是 90 次训练（全量约 70 小时，10% 约 10 小时）。图 6 是每个 beta 下的横向比较，对规模不敏感 |
| 偏差定义 | 两个选项是同一个数；真正要定的是报哪几个量 | mean(zhat - p) 等于 mean(zhat) - mean(p)，期望的线性性，恒等 |

**教师模型的三条硬标准**（写进 `build_semisynth.py` 的断言，不达标直接退出）：

1. p* 要有离散度：`P90(p*) / P10(p*) >= 5`（即 B3）；
2. p* 要可学：教师在留出集上的 AUC 明显 > 0.5；
3. 不能与参赛选手同构：配置 ≠ 主表的 MLP-CVR 基线配置。

**一个要纠正的认知**：p* 不需要「准」。半合成基准的逻辑是**宣告 p* 就是这个合成世界的真实转化概率**，
再对全部曝光按 `z ~ Bernoulli(p*(x))` 生成标签、用 π_β 单独生成观测掩码——p* 按构造就是 ground truth，
教师在现实世界偏不偏与它无关。这个说法要写进 05 §5.8 和 R7 的应对，比「主动承认教师有偏」更站得住。
顺序上，教师的 AUC 问题必须先修完（批次 1）再训，否则 p* 带着旧特征的偏差。

**规模的写法**：「半合成基准在全量上构造伪真值，beta 扫描在 10% 分层子集上完成（90 次训练），
全量复核 beta=2 单点，结论一致。」03 的 R4 降级动作本来就预设了降规模。省下的 60 小时刚好够重跑一轮。

**偏差要报的四个量**（对应 M1）：有符号偏差、相对偏差（除以伪真值均值，跨 beta 可比）、
MSE 分解（C2 的论证靠它）、MAE（可选）。

### 5.2 六条设计定稿

**B1　logging policy 不能是伪真值的确定性函数**

注释写 score 等于伪真值的 logit，那么策略是伪真值的严格单调变换，倾向得分与被估计量一一对应。
IPS/DR 靠倾向，而这个基准里倾向最大程度可学；ESMM 这类非因果方法得不到同等便利。正中 R7。

修法：让 g 带一个与伪真值独立的成分，g(x) = rho 乘 logit(p) 加 sqrt(1 - rho 平方) 乘 xi(x)。
xi 取真实 pCTR 模型的 logit 最自然（现实里日志策略本就是 CTR 模型驱动）。rho 固定 0.7，
beta 的语义不变（beta=0 仍是 MCAR）。论文里写清 rho 的含义，R7 就从「基准偏向你」
变成「基准显式控制了偏向程度」。

**B2　beta 增大会偷偷增加转化正样本数**

b 把点击率钉在 4%，但 beta 越大曝光越集中在高伪真值样本上，被观测到的转化数会随 beta 上升。
「beta 大则偏差大」与「beta 大则正样本多」混在一起。

修法：不能同时钉两个量，钉 CTR 是对的。但 metadata.json 除实际点击率外必须记实际转化数，
论文的 beta 表带这一列。

**B3　缺伪真值离散度门槛**

伪真值全挤在 0.005 附近时，beta 调不出偏差，曲线是平的。
修法：生成前断言 P90 除以 P10 大于等于 5，不达标直接 exit。否则可能跑完 90 次训练才发现。

**B4　两个种子要分开**

只有一个 `--seed`，基准生成噪声与训练噪声混在一起。
修法：基准种子固定 0，训练种子 0 到 2，论文里写明。

**B5　自检没落在代码里**

02 节 4.2 与 04 的 R7 都把「beta=0 时朴素 CVR 与纠偏方法偏差接近」定为唯一硬证据。
修法：做成 step 5，不通过 exit(1)，不是打印警告。

**B6　没有教师训练脚本**

`--teacher` 要一个 ckpt 路径，但仓库里没有产出它的命令，10 号复现清单覆盖不到 C5。
修法：补一条明确的教师训练命令进 10 号。

**顺带**：`solve_bias_for_target_ctr` 的 60 次二分精度远超需要，而每次要扫一遍全量 score。降到 40 次。

**门槛**：看**用户不交叉切分上的 CTR AUC 大于等于 0.58**，不看 CVR AUC。
原 0.58 门槛所用切分未做用户隔离——`val` 与 train 共享 85.71% 用户，模型指标实际落点 `test` 共享 47.03%，
两者都含用户记忆红利（见 D9、19 号 §0），所以门槛必须先换切分再判定。

理由：10% 上 CVR 只有约 836 个正样本，AUC 标准误约 0.017，分辨不出 0.03 以内的差异；
CTR 有约 15.6 万正样本，标准误约 0.0013，分辨率高 13 倍。而当前三配置的 CTR AUC
全在 0.524（文献 0.60 到 0.63），CTR 是每条曝光都有标签的简单任务，没有稀疏性借口，
所以它是「特征管道修没修好」的最灵敏探针。
